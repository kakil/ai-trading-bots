# Screenshots

Keep milestone screenshots, not every click.

**Naming:** `YYYY-MM-DD-short-description.png`, for example `2026-11-20-turtle-v1-strategy-tester.png`

Good examples:
- the strategy compiling cleanly
- Strategy Tester results for a logged backtest
- an alert set up and firing
- a bug before and after the fix

**Before committing:** hide account numbers, balances, email addresses and anything else personal.
