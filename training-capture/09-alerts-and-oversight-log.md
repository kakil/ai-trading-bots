# Alerts and oversight log

## Alerts
Log every alert created, changed or deleted.

```
## YYYY-MM-DD: <alert name> (created / changed / deleted)

- Strategy and version:
- Symbol / timeframe:
- Condition:
- Message:
- Delivered to: (app, email, webhook; never paste a webhook URL that contains a token)
- Expires:
- Tested? (fired as expected: PASS / FAIL / UNVERIFIED)
```

## Oversight reviews
Regular check-ins where a person reviews what the bot did.

```
## YYYY-MM-DD: Oversight review

- Period covered:
- Alerts fired:
- Matched the strategy rules? (yes / no, with details)
- Anything unexpected:
- Action taken: (none / pause / change / stop)
```
