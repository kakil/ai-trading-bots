# Training capture

This folder is the living record of how the **AI Trading Bots** course was built with Claude and TradingView. It covers what we tried, what broke, what we tested and what we learned.

It is also the raw material for the course. Interesting moments get linked to lessons in `12-course-map.md`.

## Core rules

- **Capture as you go.** Every working session gets an entry in `04-session-log.md`.
- **Don't rewrite history.** Mistakes and failed ideas stay in the record. Fix things with a new dated entry.
- **Evidence over claims.** Write down exactly what was checked and how.
- **No profit claims.** A backtest is a simulation. Paper trading isn't live trading.
- **No secrets.** No API keys, webhook tokens, account numbers or personal details.

## Philosophy

**Capture now, package later.** Don't slow the work down to make it look polished. The course gets built from the honest record.
